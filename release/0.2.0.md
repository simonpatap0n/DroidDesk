# DroidDesk 0.2.0

Cette version améliore le contrôle de l’écran Android, le transfert de fichiers et l’intégration DroidLink. Elle permet aussi à chacun d’héberger son propre relais et de choisir son domaine HTTPS.

## Nouveautés

- **Relais DroidLink configurable** : choisis ton propre domaine HTTPS dans DroidDesk et DroidLink. Aucun domaine personnel n’est imposé par le code ou les exemples publiés.
- **Déploiement maison documenté** : le relais se lance avec Docker Compose et se place derrière Nginx Proxy Manager. Les instructions couvrent le DNS, le certificat HTTPS, le pare-feu, le VPN privé et la persistance SQLite.
- **Suppression des photos depuis la galerie** : envoie une demande au téléphone; Android affiche une confirmation système avant de supprimer le fichier.
- **Montage dans Nautilus par ADB Wi-Fi** : parcoure `/sdcard` comme un système de fichiers avec madbfs et FUSE. Les dossiers privés des applications restent protégés par Android.
- **Fenêtre native scrcpy** : ouvre directement l’application scrcpy du bureau pour l’appareil ADB actif, en conservant l’adresse et le port de la connexion Wi-Fi.
- **Écran intégré amélioré** : la molette transmet le défilement à l’application Android, et l’actualisation relance aussi la recherche des icônes manquantes.
- **DroidLink Android** : configure le domaine du relais depuis l’application et confirme les demandes de suppression de photos au moyen d’une notification Android.
- **Interface et connexion** : meilleur affichage des appareils et des statuts, découverte mDNS des téléphones ADB déjà appairés, navigation améliorée et captures de démonstration anonymisées.

## Installation

### DroidDesk pour GNOME

Télécharge le code source depuis cette page, puis installe les dépendances Debian décrites dans le [README principal](../README.md#dépendances-debian). Depuis la racine du dépôt :

```sh
meson setup build --prefix="$HOME/.local"
meson install -C build
```

Ferme et relance DroidDesk si une ancienne version était déjà ouverte.

### Compagnon DroidLink

Télécharge `DroidLink-0.2.0.apk` dans les ressources de cette release, puis ouvre le fichier sur le téléphone pour l’installer. Android peut demander d’autoriser l’installation depuis cette source. L’APK n’a pas besoin d’ADB pour fonctionner.

Pour compiler l’APK toi-même, installe Java 17+, Android SDK Platform 37 et Android Build-Tools 36.0.0, puis exécute `cd droidlink && ./build-apk.sh`.

## Relais auto-hébergé

Le relais est facultatif pour DroidDesk, mais nécessaire au compagnon DroidLink. Utilise le [guide Docker Compose et Nginx Proxy Manager](../droidlink/relay/README.md). Avant de démarrer l’association, configure le même domaine HTTPS dans le menu **Configuration** de DroidDesk et dans **Accès** sur DroidLink.

Pour le montage Nautilus sans fil, installe également madbfs et FUSE depuis les dépôts de ta distribution. Le téléphone doit être déjà connecté par ADB Wi-Fi.

## Notes et limites

- La lecture des messages s’appuie sur le fournisseur SMS/MMS Android accessible par ADB. Google Messages conserve son historique RCS dans une base privée; ces conversations RCS ne sont donc pas importées comme des SMS ordinaires.
- L’envoi d’un message reste confirmé par l’application Messages Android.
- La suppression d’une photo requiert DroidLink associé, l’autorisation de notifications et l’approbation Android de la demande système.
- DroidLink transmet notifications, photos et commandes par le relais auto-hébergé. L’administrateur du relais peut voir le contenu en transit; héberge-le sur un réseau de confiance.
- Les fonctions ADB nécessitent une connexion USB autorisée ou ADB Wi-Fi. La découverte mDNS requiert le même réseau local et le débogage sans fil activé.
